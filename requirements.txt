# O fuso de Brasília, vindo do Python e não do sistema operacional.
#
# `main.py` faz ZoneInfo("America/Sao_Paulo") na LINHA 15, fora de qualquer
# função. Num sistema sem banco de fusos isso não é um erro numa tela: o
# import do app estoura e o servidor não sobe. Hoje funciona no Railway porque
# a imagem Linux traz os fusos junto; é uma dependência que a gente tem sem
# ter declarado, e que sumiria calada no dia em que a imagem base mudasse para
# uma versão enxuta.
#
# Descobri por outro caminho: no Windows do Vini essa base não existe, e
# metade da suíte morria com "No time zone found with key America/Sao_Paulo".
tzdata==2024.1
